## 🚀 نحوه اجرا به صورت محلی (Local Development)

با توجه به معماری استاتیک مدرن و مستقل از وابستگی‌های سنگین، وبسایت به آسانی با هر سرور وبی اجرا می‌شود:

```bash
# کلون کردن ریپازیتوری
git clone https://github.com/Ehsunpy/cv.git
cd cv

# اجرای سرور لوکال با پایتون
python -m http.server 8000
```

سپس در مرورگر خود آدرس زیر را باز کنید:
[http://localhost:8000](http://localhost:8000)

## 🐳 اجرای پروژه با داکر (Docker & Docker Compose)

پروژه به طور کامل داکرایز شده و با یک وب‌سرور سبک، امن و پرسرعت `nginx:alpine` به همراه فشرده‌سازی Gzip و کش استاتیک پیکربندی شده است:

### روش ۱: با استفاده از Docker Compose (توصیه‌شده)

```bash
# بیلد و اجرای کانتینر در پس‌زمینه
docker compose up -d

# مشاهده لاگ‌ها
docker compose logs -f

# متوقف‌سازی
docker compose down
```

### روش ۲: با استفاده از Dockerfile مستقیم

```bash
# ساخت ایمیج داکر
docker build -t ehsunpy-cv:latest .

# اجرای کانتینر روی پورت ۸۰۸۰
docker run -d -p 8080:80 --name ehsan-portfolio ehsunpy-cv:latest
```

سپس پورتفولیو را در آدرس زیر مشاهده نمایید:  
👉 **[http://localhost:8080](http://localhost:8080)**

## 🌐 انتشار بر روی GitHub Pages

برای فعال‌سازی وبسایت روی دامنه رایگان گیت‌هاب پیجز:
1. در صفحه ریپازیتوری در گیت‌هاب، به مسیر **Settings > Pages** بروید.
2. در بخش **Build and deployment > Source**، گزینه **Deploy from a branch** را انتخاب کنید.
3. شاخه **main** و فولدر **/(root)** را انتخاب کرده و دکمه **Save** را بزنید.
4. وبسایت شما ظرف چند دقیقه بر روی آدرس `https://ehsunpy.github.io/cv/` در دسترس خواهد بود.
